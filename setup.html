Send bank SMS from this iPhone

  1. Open Shortcuts → Automation → + → Message.
  2. Message Contains: SAR. Leave Sender empty. Choose Run Immediately, turn off Notify When Run, tap Next → New Blank Automation.
  3. Add the action Get Contents of URL. URL:
  4. Tap Show More. Method POST. Add a header: key Authorization, value:
  5. Request Body JSON, two Text fields: sender = Shortcut Input → Sender (or type iPhone), and body = Shortcut Input → Content. Tap Done.
  6. Duplicate it (long-press) for SR and ريال, and INR for Indian accounts. Each automation matches one word.

Build the Shortcut yourself

Make it once, then share it (⋯ → Share → Copy iCloud Link) and put the link in Vercel as SHORTCUT_URL: everyone else then gets the one-tap button above. Name it Send to Expense.

  1. Get File from Shortcuts folder, path Expense/device.json. Turn off Error If Not Found.
  2. If File does not have any value:
    1. Get Clipboard
    2. Get Dictionary from Clipboard
    3. If Dictionary does not have any value → Show Alert “Tap Copy my key on the Expenses setup page first” → Stop This Shortcut. End If.
    4. Save File Dictionary to Shortcuts, path Expense/device.json, Ask Where to Save off, Overwrite If File Exists on.
    5. Show Notification “Expense: this iPhone is connected” → Stop This Shortcut.
    End If.
  3. Get Dictionary from File (step 1).
  4. Get Dictionary Value for url in Dictionary; again for key.
  5. Text: Bearer + key (one space after Bearer).
  6. Get Contents of URL url: Method POST; Header Authorization = that Text; Request Body JSON: sender = Shortcut Input → Sender, body = Shortcut Input → Content.
  7. In the shortcut’s settings (ⓘ), turn on Receive input: Messages and Text.

The setup page copies {"url": "…/sms", "key": "…"}. The key file lives in iCloud Drive → Shortcuts → Expense; delete it to connect again with a new key.
